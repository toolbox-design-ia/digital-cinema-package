# Digital Cinema Package — Comandos y archivos del libro

Repositorio companion (Studio35). Cada carpeta de `capitulos/` contiene los bloques ejecutables impresos en ese capítulo, con el nombre de la sección que los explica: listos para copiar, ajustar rutas y ejecutar. El anexo del libro explica la terminal desde cero y resuelve los errores comunes.

Los comandos cortos (hasta 10 líneas) viven solo impresos en el libro; aquí están las secuencias largas, para no teclearlas a mano.

## Un repositorio, tres ediciones

Compartido por las ediciones ES/EN/FR del libro.
